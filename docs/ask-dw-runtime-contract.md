# Ask DW Runtime Contract — Normal + Deep

Ask DW is the conversational interface to Duewatch Intelligence. It is not a second, weaker brain and it is not allowed to bypass canonical state, evidence admission, reconciliation, policy authority, or server execution controls.

## Shared truth floor

Normal and Deep run against the same DW Intelligence snapshot. On the same snapshot they must agree on canonical financial facts, operational reconciliation state, execution authority, and hard safety outcome.

Normal is the default operator path: direct, sufficient, evidence-grounded, and fast. Deep adds analytical breadth: competing hypotheses, disconfirming evidence search, structural precedent, uncertainty, counterfactuals, recommendation challenge, and independent verification when those passes are relevant.

Risk may auto-escalate a Normal request internally while preserving the Normal answer shape. Safety never depends on the founder selecting Deep.

## AR jobs

Every Ask DW request is mapped into one of five AR jobs: EXPLAIN, INVESTIGATE, PREDICT, DECIDE, ACT. A model may later propose the mapping, but the runtime validates the proposed vocabulary before execution logic sees it.

## Observable reasoning

Ask DW may expose actual computation events such as entity resolution, canonical truth reads, evidence admission, contradiction checks, precedent retrieval, uncertainty assessment, verification, authority checks, and execution receipts. It must not expose or fabricate private chain-of-thought.

The current deterministic core truthfully labels Deep semantic/model passes as required-but-pending until a real model/tool adapter executes them.

## Action boundary

Conversation never grants execution authority. ACT requests still pass through current-state revalidation, policy/authority checks, reconciliation holds, action-class constraints, accounting boundaries, idempotency intent, and the server execution seam. This increment remains sandbox-only through the underlying Phase 2B workflow.

## Current scope

This increment establishes the governed runtime contract and deterministic core. It does not yet include a live foundation-model adapter, real semantic retrieval, multimodal extraction, or production provider execution.
